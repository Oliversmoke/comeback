# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability within **comeback.ai**, please report it responsibly. Do not disclose public issues for unpatched vulnerabilities.

- **Email:** security@comeback.ai
- **Scope:** Includes Soroban smart contracts (`comeback-contract`), Node/Kotlin backend services, API gateways, and client auth mechanisms.

## Audit Disclaimer
Smart contracts in `comeback-contract` are provided as-is under the MIT License and are currently pending formal third-party security audits. Use at your own risk on Stellar Testnet and Mainnet.
